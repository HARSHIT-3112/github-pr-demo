# github-pr-demo

Practice repository for the **Introduction to GitHub** demo class.

Your goal today: open your **first pull request**.

## How to contribute (browser only, no installation)

1. Open the [`students`](students/) folder.
2. Click **Add file → Create new file**.
3. Name the file `your-github-username.md` (for example `HARSHIT-3112.md`).
4. Write your name and one line about yourself.
5. Click **Commit changes → Propose changes**. GitHub will create a *fork* (your own copy) for you.
6. Click **Create pull request**.
7. Paste your PR link in the meeting chat.

Your PR gets reviewed and merged live during the class.

## Rules

- Only add **one new file**, named after your GitHub username.
- Don't edit anyone else's file. That way there are no merge conflicts.

## Key words

| Word | Meaning |
| --- | --- |
| Repository | The project folder plus its full history |
| Commit | A saved snapshot with a message |
| Branch | A parallel copy to work on safely |
| Fork | Your own copy of someone else's repository |
| Pull request | "Please review and merge my changes" |
